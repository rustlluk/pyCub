move_position(joints: icub_pybullet.utils.JOINTS | List[icub_pybullet.utils.JOINTS] | icub_pybullet.utils.JOINTS_IDS | List[icub_pybullet.utils.JOINTS_IDS], positions: float | List[float], wait: bool | None = True, velocity: float | None = 1, set_col_state: bool | None = True, check_collision: bool | None = True, timeout: float | None = None) → None

Move one joint or a list of joints to target angles in radians.

Parameters:

  • joints – Joint name or ID, or a list of joints to move together.

  • positions – Target angle in radians for each joint, in the same order.

  • wait – Step the simulation until the movement finishes.

  • velocity – Maximum joint speed in radians per second.

  • set_col_state – Clear the collision flag at the start of this move.

  • check_collision – Check for collisions while waiting for the move.

  • timeout – Maximum motion time in seconds, or None for no time limit.
