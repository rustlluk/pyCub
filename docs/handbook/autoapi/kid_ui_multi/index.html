kid_ui_multi

Start multiple independent kid_ui.py instances (each with its own simulation, web port, and video port) and print the addresses used to connect to them. Stop with Ctrl+C.

Usage:

python3 kid_ui_multi.py [-n 5] [–port 5001] [–stream-port 6001] [–world ball] [–log-dir DIR]
