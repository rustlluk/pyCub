icub_pybullet.kid_api

High-level beginner-friendly Python API for pyCub („Kid Programming“ & „Scratch“ Blockly runtime).

Allows students to control iCub with intuitive one-line commands without writing simulation loops or radian conversions, both inside the standalone desktop app (Modes 2 & 3) and when executed directly as a standard .py script.

Exceptions

KidScriptStopped

Raised cooperatively to stop a running Kid Scratch / Kid Programming script immediately.
