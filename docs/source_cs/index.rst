Příručka pyCub Studia
=====================

.. container:: handbook-intro

   .. rst-class:: introduction

      Naučte se ovládat humanoidního robota iCub v simulaci. Začněte jednoduchým
      zamáváním, napište vlastní řídicí program a otestujte jej v kurzovních cvičeních.

   .. image:: ../static/images/icub.png
      :class: handbook-robot
      :alt: Simulovaný humanoidní robot iCub mávající za stolem s červeným míčkem

.. rst-class:: handbook-sections

* :doc:`Použití Studia <studio>`

  Vyberte režim, nastavte pracovní složku a spusťte simulaci.

* :doc:`Programování robota <programming>`

  Pohybujte klouby, čtěte senzory a prohlížejte nápovědu k funkcím v Pythonu.

* :doc:`Ukázkové programy <examples>`

  Prozkoumejte hotové ukázky kloubového, kartézského i dotykového řízení.

* :doc:`Kurzovní cvičení <exercises>`

  Procvičte si plánování pohybu, řízení pohledu a uchopení objektů.

* :doc:`Dokumentace projektu (README) <readme>`

  Instalace, Docker, přehled funkcí a citace (v angličtině).

* :doc:`API reference <autoapi/index>`

  Přehled tříd, funkcí a jejich parametrů (v angličtině podle zdrojového kódu).
